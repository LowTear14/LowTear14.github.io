Projects

Padilla Veterinary Clinic

Padilla Veterinary Clinic System is a web app I built to replace the clinic's manual record-keeping, inventory counting, and phone-based updates. Pet owners can book appointments without double-booking, follow their pet's boarding status, and message the clinic, while staff manage clients, confirm appointments, and track stock from one admin portal, where inventory is deducted automatically when an appointment is confirmed. It's built with React and Firebase (Firestore, Authentication, and Cloud Functions), with automated email verification and reminders.
